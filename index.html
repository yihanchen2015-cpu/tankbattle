💥 武器与大招系统

每辆载具配备三种武器，按 T 循环切换：

• 主炮 - 对地主力；可以攻击直升机，但仅造成 40% 伤害

• 机枪 - 射速快且可穿透 3 个地面目标，不能攻击直升机

• 高射炮 - 可越障并在升空后锁定一次最近敌人；制导距离、时间和转向角速度有限

每辆坦克都有独特的终极技能，冷却完成后按 G 释放。

💡 直升机对地需飞到目标正上方投弹；遇到空中目标会对齐高度并使用空对空机枪。

🏰 据点、基地与胜利条件

据点 - 地图上的菱形标记，停留可占领并获得团队积分；据点不再生成援军。

基地增援 - 蓝红双方基地均每 15 秒部署一辆坦克；基地被摧毁后停止部署。

基地 - 双方各有基地，摧毁敌方基地即可获胜！

胜利条件：摧毁敌方基地 / 时间结束时据点更多 / 全歼敌人

💡 占领据点能压缩敌方活动空间。优先摧毁敌方基地是最快的胜利方式！

📖 游戏介绍

🎮 游戏模式

🏛 经典模式

蓝方10辆坦克 vs 红方10辆坦克，在缩小后的紧凑地图争夺3个据点（海岛为5个）。据点会随持有时间升级并每分钟产分，双方基地均每15秒部署一辆援军。

🛡 守点模式

蓝方仅有一个基地，3个据点全被红方占领。蓝方坦克弹药×3且无视负重惩罚，必须在3分钟内守住基地。双方基地仍按各自周期部署增援。

🌙 绝地偷袭

蓝方10辆坦克深入敌后，面对红方30辆重兵把守。全程黑夜模式，也可利用成长据点获取持续分数；主要目标仍是摧毁红方基地。

🚛 护送模式

地图不设基地和普通据点，A、B分别位于地图两端。巨型全金VIP会持续向B点突击，蓝方AI围绕它全力推进，红方AI在前方组成阻击线；红军贴近会让VIP减速，但不会令它停车。

💀 死斗模式

没有据点、没有基地、也不计算团队分数。双方持续增援，率先取得50次击杀的阵营立即获胜。

👑 首领模式

地图中心出现巨型BOSS坦克。拿到最后一击的阵营获得5,000分，并得到30秒全队攻防与机动增益。

🏆 团队计分与战况

蓝红双方共享各自的团队分数，玩家与 AI 队友的行为都会计分。比赛触发结束后，统一按总分判定蓝方胜利、红方胜利或平局。

  • 击毁普通地面单位：+250 分
  • 击毁牛牛直升机：+300 分
  • 占领据点：+500 分
  • 据点每持有1分钟：每级 +200 分，并自动升级
  • 首领最后一击：+5,000 分
  • 摧毁敌方基地：+10,000,000 分

HUD 实时显示“蓝 多少分 | 红 多少分”，下方公告栏会播报击杀、占点、夺旗和摧毁基地事件。

隐藏加时：如果正常时间结束时双方平分，会触发 1 分钟“绝地肉搏”。存活单位满血并聚集到地图中央，大招回满、弹药无限，已阵亡单位不会复活。

🗺️ 战场环境

🏜 沙漠风暴

橙黄色开阔战场，障碍少且视野更大。随机沙尘暴会压缩视野，并让牛牛直升机减速、受侧风吹移。

❄️ 雪地突袭

白色雪原上会保留履带轨迹。地面载具停驶超过 5 秒后引擎逐渐冻结，会减速并持续掉血；重新移动可逐渐恢复。

🏙 城市巷战

规则街区、十字路口、道路中线和多层建筑构成密集城市。重火力可炸塌建筑的一部分，形成低矮但仍能挡车、挡弹的废墟掩体。直升机受楼群乱流影响，速度降低 22%。

🏝 海岛争夺

整张地图以水域为底，由 5 座独立小岛和有真实高度的拱桥网组成，每座岛都有一个据点。普通坦克可冒险入水，但会大幅减速并因车体进水持续掉血；多多号步战车免疫进水伤害，水中速度为 30%。

🌋 火山熔岩

200–400 宽的熔岩河会缓慢流动。地面载具在河中每秒受到 100 伤害，直升机会被热气流自动抬升；每 30–60 秒喷发的熔岩球造成 150 伤害和 3 秒减速。地图边缘的冷却结晶为坦克提供 +0.5 装甲。

🏗 废弃工厂

约 3000×3000 的室内厂房分为面积相同的 B1、1F 和 2F，每层净高 500，拥有不透明的实体楼板与天花板，建筑外墙就是战场边界，每层各有一个据点。Ammo.js 物理让油桶滚动、坠井、被电梯压爆，也让传送带与工业风扇真实推动物体；铲车会叉起并抛下货物，2F 起重机能用约束抓取和投掷坦克或油桶。1F 的维修机器人会修复设施，液压机和电梯还能把玩家压伤并“拍扁”5 秒。楼层之间以带护栏的实体斜坡和开放式升降平台连接，三层处于同一个连续的立体空间，并使用标准战术相机。

💥 武器与空中单位

  • 主炮：可调仰角的抛射弹道，对地高伤害；命中直升机时伤害 ×0.4。只有弹丸 XYZ 坐标均与目标重叠才算命中。
  • 机枪：低仰角、射程有限，无法命中直升机。
  • 高射炮：仰角可调，带真实高度层次的抛射弹道并可越障；升空 0.2 秒后仅在 600 范围内锁定一次，最多制导 0.85 秒，无法急转弯或反复换目标。
  • 牛牛直升机：可在 100–1000 高度间飞行并越水；使用垂直向下投放、覆盖 150×150 区域的炸药包和只能攻击飞行单位的空对空机枪。高度超过障碍物后才能越过，连续撞击 4 次会起火。
  • 地图对空惩罚：经典图防空雷达增幅高射伤害；沙漠有沙尘侧风；城市有楼群乱流；雪地会旋翼结冰；海岛有强海风且高射伤害更高；火山热气流会强制抬升；工厂钢架乱流会降低飞行速度。
  • APS：每辆载具仅 4 次拦截，每次启动后需冷却 15 秒才能再次拦截。
  • 基地防御：基地拥有 50,000 HP，自动炮塔通常每 2 秒发射一枚基础伤害 120 的炮弹。
  • 基地护盾：超过 3 辆红方 AI 进入蓝方基地 300 范围后启动；范围内蓝方坦克减伤 30%，并额外恢复每秒 6% 最大生命。围攻解除后护盾保留 6 秒。
  • 中立狙击塔：地图中心固定生成 1 座，每 10 秒用大型紫色炮弹攻击当前个人分数最高的存活坦克，单发伤害 150；炮弹会被建筑、岩石等障碍物挡住。
  • 空投补给：战场会定期空投带降落伞的补给箱，任何阵营均可拾取，可修复生命并补充弹药和 1 次 APS。
  • 武器配件：地图散布高爆弹、穿甲弹、快速装填、稳定器、消音器和扩容弹匣；拾取后装到当前武器，每种武器有 2 个槽位，满槽后替换最早配件。
  • 坦克涂装：黄金、暗影、烈焰和冰雪涂装由熟练度与生涯战绩解锁，只改变外观；另有一种不会主动公布线索的隐藏涂装。
  • 工程维修：多多号工程车按 R 可维修 175 范围内最残血的存活队友，不能维修自己。
  • 弹药架殉爆：车辆被击毁时，剩余弹药越多越可能殉爆；爆风会造成范围伤害，敌我不分并可能引发连锁殉爆。
  • 地形破坏：主炮、火箭、炸药包与大型爆炸可以破坏树木、岩石等小型障碍；城市建筑会从受击侧局部坍塌并生成形状不同的新废墟掩体。飞散碎块带有重力、旋转、反弹与阻尼。
  • 战场传闻：有人见过贴着墙面改变方向的炮弹，也有人在几乎全军覆没时收到过来源不明的无线电信号……

🎯 操作说明

  • WASD / 方向键：移动坦克
  • 鼠标：控制炮塔瞄准方向
  • F 键 / 射击按钮：开火
  • T 键 / 切换按钮：切换主炮 / 机枪 / 高射炮
  • 1 / 2 / 3 / 4：直接选择武器；Q 键：地面载具在脚下快速展开烟雾弹；[ / ]：降低 / 提高主炮或高射炮仰角（机枪仰角固定）
  • G 键 / 大招按钮：释放终极技能
  • R 键 / 维修按钮：工程车维修范围内队友
  • 战术视角：游戏统一使用 Three.js 真 3D 战场
  • 直升机高度：E / 空格上升，Q / Shift 下降
  • 移动端 / 平板：按触控能力显示摇杆，不再按屏幕宽度判断；直升机另有上升/下降按钮
  • 阵亡回放：使用独立 Three.js 3D 导演镜头，从致命炮弹发射开始以 0.3× 慢放跟随弹道；接近目标时镜头拉远，命中后环绕展示车体解体。
  • 战场音效：引擎负载会改变轰鸣音高；主炮、机枪、高射炮有独立音色，开火、命中与击杀会按强度震动镜头。

◈ Three.js 真 3D 战场

战斗统一使用 Three.js + WebGL 真 3D 战场，采用锁定地图北方的战术相机：镜头只平移、不会随坦克转弯旋转，W/S/A/D 始终对应屏幕上下左右。战场同时提供敌我名称牌、玩家定位信标、伤害飘字、据点进度和直升机预警。直升机与高射弹在战斗数据中都具有真实 Z 高度，高射弹使用垂直速度和重力计算弹道。

🔥 铁三角（通吃组合）

多多号主战 + 星辰27B + 星辰27S
运作逻辑：27B开启绝对领域堵路反弹 → 敌方犹豫/绕路 → 多多主战毁灭齐射扇形扫射 → 无处可躲
左研30绕后？ → 27S跃迁揭露+护盾保护 → 隐身失效被集火
左研29 rush？ → 27B反弹残血 → 齐射收割
⚠ 天敌：多多号自移车（天罚之钉无视装甲+反弹，3秒锁定可打断齐射充能）

🌪 双风突袭（速度压制）

左研29 + 左研30 + 星辰27S
运作逻辑：左研29疾风冲正面吸引 → 左研30隐身绕后刺杀指挥官/输出 → 27S跃迁救场或补刀
极限速度：左研29可达17.82，左研30可达17.55，几乎与子弹同速
3秒rush：12秒横穿全图，敌方反应时间极短
⚠ 天敌：星辰27B（反弹让rush变自杀）、多多号步战车（弹幕扫射无法躲避）

🛡 不死军团（据点绞肉）

左研X + 星辰27A×2 + 星辰27B + 多多号步战车
运作逻辑：指挥官buff全员（射速+30%、速度+20%、装甲+0.5）→ 27B堵门反弹 → 27A双护盾叠加4000HP → 步战车弹幕风暴无限输出
数值恐怖：步战车实际射速3.9倍 × 无限弹药 × 1.5倍伤害 = 5.85倍持续输出
27B实际装甲：2.5 × 5 × 1.5 = 18.75倍
⚠ 天敌：左研30隐身刺杀指挥官（buff消失全盘崩）、多多号自移车天罚之钉（无视装甲穿透）

🎯 天罚核心（远程狙杀）

多多号自移车 + 左研30 + 星辰27S
运作逻辑：自移车3秒锁定敌方核心（27B/指挥官）→ 天罚之钉500伤害穿透秒杀 → 左研30隐身保护自移车，现身眩晕打断者 → 27S跃迁双保险
克制关系：专杀铁三角（天罚破27B反弹）、专杀指挥官（500伤害秒杀）、专杀步战车（打断弹幕风暴）
射程优势：5000射程覆盖半个地图，敌方够不着
⚠ 天敌：左研29疾风突袭（3秒内冲到脸上打断锁定）、被近身必死（自身极脆）

💀 三体自杀（人墙消耗）

左研1 × 3 + 星辰27B
运作逻辑：三辆左研1轮流过载引擎冲锋 → 第一辆瘫痪在敌方阵前 → 第二辆再冲形成人墙 → 第三辆收尾 → 27B在后方反弹输出
心理威慑：敌方看到三辆左研1冲过来不敢不打（怕堵路），打了又心疼弹药
成本极低：左研1最廉价，死了不心疼
⚠ 天敌：多多号自移车（不浪费子弹，直接天罚点杀瘫痪坦克）、左研30（隐身不触发仇恨直接穿过去）

⚡ 闪电猎杀（高速斩首）

左研29 + 多多号自移车
运作逻辑：左研29疾风突袭绕后 → 轨迹减速敌方 → 自移车天罚之钉锁定无法躲避的目标 → 500伤害秒杀
速度差：左研29极限17.82 vs 左研30极限17.55，快0.27，可追上任何逃跑目标
专杀对象：星辰27B（减速后无法逃跑，天罚无视装甲）
⚠ 天敌：星辰27S（跃迁揭露+护盾保护目标）、弹幕风暴（范围扫射无法躲避）

🎭 克制关系速查

  • 左研30隐身流 → 被星辰27S跃迁揭露、被地雷区逼现身
  • 星辰27B反弹流 → 被多多号自移车天罚之钉无视、被左研1人墙绕过
  • 多多号步战车弹幕 → 被自移车远程点杀、被左研29高速打断
  • 多多号自移车狙击 → 被左研29疾风突袭打断锁定、被左研30隐身贴近
  • 左研X指挥官buff → 被左研30隐身刺杀（斩首战术）
  • 左研1自杀冲锋 → 被无视（不打它）、被天罚点杀（不浪费子弹）
